# Figure-ready data

CSV tables derive directly from the chapter JSONs. Random64 uses 0–100 F1; pilot48 includes both 0–1 and 0–100 columns. One-question rows have different targets/transforms and should be faceted, not combined into a six-layer curve. Five 192-mask repeats are repeated measurements on the same 48 questions, not 240 independent questions. See chapters for confidence intervals, budgets and source details.
