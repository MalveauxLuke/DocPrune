# Source snapshots

Byte-for-byte copies of selected existing analyses and context files. source-manifest.json maps each hash-named snapshot to its original absolute path and full SHA-256. Sources over 2 MB are referenced rather than copied. Archived raw 1,213-question files (~1 GB) are not bundled. These source snapshots may contain historical wording qualified or corrected by the packet chapters; the writer should read both.
