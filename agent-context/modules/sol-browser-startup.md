# Start SOL in the browser

User-provided workflow, recorded 2026-09-11.

1. Open the ASU Chrome profile (`lmalveau`) and visit [sol.asu.edu](https://sol.asu.edu/).
2. Go to **Interactive Sessions**.
3. If a session is running, click **Open VSCode Browser Web**.
4. If none is running, click **Restart** on the most recent session. Wait until it is ready, then click **Open VSCode Browser Web**.
5. If prompted to **Open GitHub**, click it and paste the code copied to the clipboard into the GitHub device-activation page. Complete activation, then open the browser session.

Reuse the existing/recent session instead of creating an unnecessarily large new allocation. Once connected, read `docs/SOL_INSTRUCTIONS.md`, `sol/AGENTS.md`, and `sol/CURRENT_SOL_TASK.md` before executing work. Check existing environment issues and request only the resources the task needs.
