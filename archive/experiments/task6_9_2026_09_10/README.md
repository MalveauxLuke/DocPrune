# Retired experiment archive — 2026-09-10

Historical reference only. Nothing below selects an active task or grants current
execution authority. Original files retain their text, including old claims of
active status, model pins, absolute paths and launch commands.

The tree preserves original repository-relative paths. `MANIFEST.json` records
SHA-256 for every moved file and every original snapshot of a changed file.
Launchers may refer to their former locations and must not be run from this archive
as if they were current launchers. Restore the recorded original tree to reproduce
an old checkout, and independently satisfy current execution requirements.

- `docs/experiments/regional-attribution/`: plans, logs and prior scientific evidence.
- `agent-context/`: retired task handoffs.
- `h200/`, `sol/handoffs/`: historical execution contracts and environment records.
- `examples/`: numbered experiment wrappers, scheduler scripts and legacy environments.
- `snapshots/`: originals of edited navigation, documentation and tests, retaining their repository-relative paths.

Installed library modules remain in `src/docprune/` where reuse or dependency
removal requires review. [Current work](../../../docs/experiments/corrective-selection/README.md).
